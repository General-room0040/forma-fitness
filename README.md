# FORMA FITNESS
แดชบอร์ดสุขภาพส่วนตัว (HTML/CSS/JS ล้วน) ข้อมูลเก็บใน localStorage ของเบราว์เซอร์

## เผยแพร่ด้วย GitHub Pages
Settings → Pages → Deploy from a branch → main / (root)

## ติดตั้งบน iPhone
เปิดใน Safari → ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม

## สถานะ
- ใช้งานได้: 10 หน้า, บันทึกอาหาร/ฝึก/นอน/น้ำหนัก, คำนวณ BMR/TDEE, Export/Import, PWA
- ยังไม่ทำ: เชื่อม Supabase (มี schema ใน supabase/migrations), AI สแกนอาหาร, iOS HealthKit Companion, เชื่อม Amazfit
- อย่าใส่ API Key หรือ Service Role Key ลงในไฟล์ใน repo นี้
